# SecureLab V1

A simple React + Vite MVP for a secure coding learning SaaS.

## Included
- Marketing landing page
- Learner dashboard
- Six beginner modules
- Vulnerable/risky vs safer examples
- Safe local simulations (no external targets)
- Knowledge checks
- Browser localStorage progress
- Completion certificate page
- Responsive layout

## Run locally
```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Production build
```bash
npm run build
```

## V1 note
The penetration-testing content is deliberately simulated. It does not target external systems or provide a live vulnerable environment.
